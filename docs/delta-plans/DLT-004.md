- Delta design S2 (Carbonyl spawn), S3 (child-exited wiring), S5 (URL polling)
- Chromium CDP `/json/list` response format:
  ```json
  [{"id":"ABC","type":"page","title":"Page Title","url":"https://example.com","webSocketDebuggerUrl":"ws://127.0.0.1:19300/devtools/page/ABC"}]
  ```
  Target selection: first entry where `"type" == "page"`. Ignore `browser` and `service_worker` entries.
- `minreq` crate: synchronous HTTP GET — `minreq::get(url).send()` returns `Result<Response>`, body via `.body.into_json()` or manual parse
- DES-002 (callback event wiring) — static method pattern for GTK signal wiring that needs `Rc<RefCell<Self>>`

### Steps

#### Step 9: Add browser state fields to SessionManager

- Modify: `src/session/manager.rs`
- What to do: Add `browser_panes: RefCell<HashMap<String, BrowserPaneState>>` and `next_debug_port: Cell<u16>` (init 19300) to SessionManager struct and constructor
- Test: Compiles

#### Step 10: Add allocate_debug_port helper

- Modify: `src/session/manager.rs`
- What to do: Add `fn allocate_debug_port(&self) -> u16` — reads current `next_debug_port`, increments, returns the read value
- Test: Unit test: sequential calls return 19300, 19301, 19302

#### Step 11: Add create_browser_session method

- Modify: `src/session/manager.rs`
- What to do: Add `pub fn create_browser_session(&mut self, url: &str) -> Result<String, String>`:
  - Check `carbonyl_available()`, return `Err("Carbonyl is not installed...")` if missing
  - Create `Session` via `Session::new_browser(url.to_string())`
  - Create `SplitView` with single pane, allocate debug port
  - Spawn Carbonyl: `terminal.spawn_command(&["carbonyl", "--remote-debugging-port", &port_str, url], None, &env_refs)`
  - Wire VTE signals: `wire_vte_signals` (for title updates), then wire `child-exited`, `pane_focus`, `bell`, `status` via static methods
  - Register `BrowserPaneState` in `browser_panes` HashMap
  - Start URL poll timer
  - Register session via `register_session`
  - Return `Ok(session_id)`
- Test: Manual: creates session with browser icon when Carbonyl installed; returns error when not

#### Step 12: Add split_with_browser static method

- Modify: `src/session/manager.rs`
- What to do: Add `pub fn split_with_browser(self_ref: &Rc<RefCell<Self>>, url: &str) -> bool` following `split_active_pane` pattern (static method needed for `Rc<RefCell<Self>>` signal wiring per DES-002):
  - Check `carbonyl_available()` via `self_ref.borrow()`
  - Split focused pane via `sv.split(orientation, &config)` (use horizontal by default)
  - Allocate debug port, spawn Carbonyl in new pane
  - Wire signals (child-exited, pane focus, bell, status) via static methods
  - Register `BrowserPaneState`, start URL poll timer
  - Rebuild widget tree, focus new pane
  - `notify_state_changed()`
- Test: Manual: browser pane appears alongside shell pane in split

#### Step 13: Add start_url_poll method

- Modify: `src/session/manager.rs`
- What to do: Add `fn start_url_poll(&self, pane_id: &str, session_id: &str, debug_port: u16)`:
  - `glib::timeout_add_local` (500ms, repeating) closure capturing `pane_id`, `session_id`, `debug_port`, `sidebar`, `browser_panes` refs
  - `minreq::get(format!("http://127.0.0.1:{debug_port}/json/list")).send()`
  - Parse JSON array, find first target where `type == "page"`
  - If URL changed: update `BrowserPaneState.url`; if this pane is focused in its session → `sidebar.update_browser_display(session_id, title, url)`
  - If title changed: update `BrowserPaneState.page_title`; if focused → `sidebar.update_title(session_id, &title)`
  - On URL or title change: call `notify_state_changed()` to trigger DES-003 debounced save
  - On connection failure: increment `consecutive_failures`; if 10+ → return `glib::ControlFlow::Break`
  - Store `SourceId` in `BrowserPaneState.poll_timer`
- Test: Manual: sidebar updates when navigating in browser

#### Step 14: Add stop_url_poll helper and extend close_pane cleanup

- Modify: `src/session/manager.rs`
- What to do:
  - Add `fn stop_url_poll(&self, pane_id: &str)` — if `browser_panes` has entry for pane_id, cancel poll timer via `source_id.remove()`, remove entry
  - In `close_pane()` (line 723): after removing from `session_cwds`, also call `stop_url_poll(pane_id)` to clean up browser state
- Test: Manual: closing browser pane stops poll timer, no GLib warnings

#### Step 15: Extend destroy_session for browser cleanup

- Modify: `src/session/manager.rs`
- What to do: In `destroy_session()` (line 350), before removing split view, iterate all pane IDs and call `stop_url_poll` for each that has a `BrowserPaneState` entry
- Test: Manual: closing browser-only session cleans up without GLib warnings

## Notes

- BrowserPaneState placed in session/manager.rs (not session/mod.rs) because it's runtime-only state managed by SessionManager — not part of the serializable Session model
- `notify_state_changed()` used in URL poll handler triggers the existing debounced persistence (DES-003) — no new dirty flag needed, the existing on_state_changed callback chain handles it
- Port 19300 chosen as well above typical service ports; collision handling is Carbonyl's immediate exit → child-exited → pane closes
- Carbonyl detection uses `std::process::Command::new("which")` — no additional crate dependency

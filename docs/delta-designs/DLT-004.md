### Flagged Unknowns

#### S5 — URL change tracking
The terminal-based browser needs to communicate URL changes back to seemux as the user navigates. This could work via OSC title sequences (if the browser sets the terminal title to the page title or URL), or via a specific OSC escape sequence. Investigate OSC 2 (window title) and OSC 7 (current directory/URL) as candidates. The exact mechanism depends on which browser tool is chosen (Carbonyl vs alternatives) and what escape sequences it emits. This should be investigated during the design phase once the browser tool is selected.
